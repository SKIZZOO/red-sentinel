# Contributing to Red Sentinel

Thank you for helping improve Red Sentinel!

## Getting started

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Test your changes.
5. Open a pull request.

## Guidelines

- Keep code clean and documented.
- Avoid exposing secrets.
- Follow existing project style.
- Explain why changes are needed.

## Bug reports

Include:

- What happened
- Expected behavior
- Steps to reproduce
- Logs if available

Thank you for contributing 💜
